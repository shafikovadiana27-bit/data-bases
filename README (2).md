# PostgreSQL Database Labs

Учебный проект по дисциплине **«Базы данных»**, выполненный на PostgreSQL.

Репозиторий собран по материалам пяти лабораторных работ. SQL-код восстановлен из отчетов и вынесен в отдельные скрипты, чтобы можно было посмотреть не только результаты на скриншотах, но и сами запросы.

## Стек

- PostgreSQL
- SQL
- PL/pgSQL
- DBeaver
- Postgres.app
- `pg_dump`
- `pg_restore`
- `pg_basebackup`

## Лабораторная работа №1 — SQL и работа с данными

В `lab1.sql` собраны:

- сортировка через `ORDER BY`;

- строковые функции `SUBSTRING`, `LENGTH`;
- `CASE`;
- агрегатные функции и `GROUP BY`;

- `ROLLUP` и `GROUPING`;

- `INSERT`, `UPDATE`, `DELETE`;

## Лабораторная работа №2 — Целостность данных

## Важно

Код собран непосредственно из лабораторных отчетов. Некоторые запросы:

- намеренно вызывают ошибки для демонстрации ограничений;
- изменяют или удаляют данные;
- зависят от состояния демонстрационной базы;
- требуют запуска в нескольких SQL-сессиях;
- используют локальные пути macOS из исходной лабораторной работы.

Поэтому файлы лучше воспринимать как **набор воспроизводимых примеров по темам**, а не как один скрипт, который необходимо запускать целиком сверху вниз.

## Что показывает проект

Проект демонстрирует практическую работу с PostgreSQL на нескольких уровнях: написание SQL-запросов, проектирование ограничений целостности, управление транзакциями и блокировками, создание серверной логики на PL/pgSQL, работа с представлениями и временными таблицами, а также базовые задачи администрирования и резервного копирования.
